# Ñam Ñam
Arrastra la comida a la boquita, ¡y limpia con la servilleta! Funciona sin internet una vez instalada.
## Publicar con GitHub Pages (igual que Patitas y Mimitos)
1. Repositorio nuevo en GitHub (público). 2. Sube index.html, sw.js, manifest.json, icon.png a la raíz.
3. Settings > Pages > Branch: main, / (root). 4. Abre la dirección en Safari del iPad (una vez con internet).
5. Compartir > Añadir a pantalla de inicio. Después funciona sin wifi.
